Setup instruction: I.Clone the Repository , II.Create Virtual Environment , III.Install Dependencies , IV.Run the FastAPI Server , V.Open the Application
How to run the application: I.Start FastAPI backend using: uvicorn main:app --reload , II.Open the browser, III.Fill the form fields with farm input data , IV.Click Generate PDF , V.Preview the generated PDF , VI.Download it to your device.
Libraries used: fastapi , uvicorn , jinja2 , python-multipart , reportlab , matplotlib
